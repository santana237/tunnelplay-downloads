# TunnelPlay : téléchargements

Fichiers officiels de TunnelPlay, publiés par l'équipe TunnelPlay. Site : https://tunnelplay.ca

| Fichier | Pour |
| --- | --- |
| `tunnelplay-tv.apk` | Téléviseurs Android et boîtiers non Google Play |
| `tunnelplay-windows-setup.exe` | Windows 10 et 11 (64 bits) |
| `tunnelplay-macos.pkg` | macOS 12 ou plus récent (puce Apple et Intel), signé et notarisé par Apple |
| `tunnelplay-linux.AppImage`, `tunnelplay-linux.deb` | Linux 64 bits |

Dernière version : https://github.com/santana237/tunnelplay-downloads/releases/latest

Sur téléphone, installez TunnelPlay depuis Google Play.
